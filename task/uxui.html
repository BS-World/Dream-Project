UX / UI Design Tasks

Hands-on UX / UI design tasks covering user research, wireframing, prototyping, usability testing, and modern interface design best practices

View Tasks Submission Guide

Objective

Teach interns the fundamentals of user experience (UX) and user interface (UI) design — research, wireframing, prototyping, visual design, and handoff-ready assets. The tasks focus on practical deliverables that designers produce in real projects.

Features

  • User research & persona creation
  • Low-fidelity wireframes & high-fidelity mockups
  • Interactive prototypes (Figma/Adobe XD)
  • Design systems & component libraries
  • Developer handoff assets & documentation

Tools

Figma Adobe XD Sketch Illustrator Photoshop Miro / FigJam

Beginner Level Tasks

  • Create a user persona for a target audience (1 page).
  • Sketch low-fidelity wireframes for a 3-screen mobile app (paper or Figma).
  • Design a simple onboarding screen and settings screen (high-fidelity mockup).
  • Prepare a short design rationale (1 paragraph) explaining choices.

Note: Out of the 4 main tasks given below, you are required to complete any 3 tasks.

Tasks (4)

Goal

Design a complete UX case study for a mobile app (e.g., task manager, fitness tracker).

Requirements
  • User research summary and personas
  • User flows and wireframes (low & mid fidelity)
  • High-fidelity prototype (Figma/Adobe XD) with 4–6 screens
Deliverables
  1. Figma/Adobe XD link (prototype)
  2. PDF summary (case study)

Goal

Design a conversion-focused landing page for a product or service.

Requirements
  • Wireframe + high-fidelity mockup (desktop & mobile)
  • Design hero section, features, testimonials, and CTA
  • Color palette, typography choices, and component specs
Deliverables
  1. Design files (Figma/XD) and exported PNGs
  2. Short design rationale

Goal

Create a small design system: colors, typography, buttons, form elements, and cards.

Requirements
  • Define tokens (colors, spacing, font sizes)
  • Create components in Figma with variants
  • Provide usage guidelines
Deliverables
  1. Design system file (Figma) + PDF guidelines
  2. Component screenshots

Goal

Conduct basic usability tests on a prototype and iterate based on feedback.

Requirements
  • Prepare 5–6 test tasks for users
  • Run 3–5 remote usability tests (record notes)
  • Make 2–3 design iterations and justify changes
Deliverables
  1. Usability report (observations + metrics)
  2. Before/after design comparisons

How to Submit Your Tasks

  1. For each task:
    • Create a separate document (DOC, DOCX, or PDF) explaining the task and attach screenshots and links.
    • Include Figma/Adobe XD prototypes or exported images where applicable.
  2. Upload your documents:
    • Upload to Google Drive or GitHub (public link) or share a Figma file link with view access.
  3. Submit your links:
    • Copy the public links and go to the Task Submission page.
    • Paste the links clearly mentioning Task numbers.

Tip: Provide clear annotations and an organized Figma file for quicker review.
