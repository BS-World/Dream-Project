Machine Learning Tasks

Objective

Strengthen your Machine Learning foundation by completing hands-on projects using Python and ML libraries. Learn data preprocessing, model building, and evaluation.

Features

  • Real-world datasets and supervised learning tasks.
  • Practice data preprocessing, feature selection, and model training.
  • Use libraries like Scikit-learn, Pandas, and Matplotlib.

Technologies

  • Python
  • Scikit-learn
  • Pandas and NumPy
  • Matplotlib / Seaborn

Tasks

Task 1: Iris Classification

Build a classification model using the Iris dataset. Use decision tree or logistic regression to predict the flower species.

Download Dataset

Task 2: House Price Prediction

Create a linear regression model to predict house prices using the Boston Housing dataset or similar.

Download Dataset

Task 3: Titanic Survival Prediction

Use logistic regression to predict passenger survival using the Titanic dataset. Apply preprocessing, encoding, and evaluation.
