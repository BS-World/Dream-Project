UX/UI Design Tasks

Objective

Enhance your UX/UI design skills by solving practical tasks. Learn the basics of wireframing, prototyping, and visual design principles.

Features

  • Create low-fidelity wireframes.
  • Design interactive prototypes.
  • Apply color theory and typography principles.

Technologies

  • Figma
  • Adobe XD
  • Sketch
  • Canva

Tasks

Task 1: Create a Wireframe

Design a low-fidelity wireframe for a landing page using Figma or Adobe XD.

Task 2: Design a Mobile App UI

Create a simple mobile app UI with at least 3 screens and navigation.

Task 3: Build a Prototype

Develop an interactive prototype using Adobe XD or Figma.

Task 4: Apply Color and Typography

Create a style guide with color palette and typography guidelines.
